# GIFTERA website prototype

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styling, 3D-inspired effects and animations
- `script.js` — marketplace interactions, demo listings, dashboard and scroll effects

## Run locally
Keep all three files in the same folder and open `index.html` in a modern browser. No build tools are required.

## Deploy
Upload all three files together to your hosting provider (for example, Cloudflare Pages). Do not upload only `index.html`; it links to `styles.css` and `script.js`.

## Prototype limitations
This is a front-end demo. Listings and requests are stored in the visitor's browser using localStorage. It does not provide real accounts, public multi-user listings, secure image uploads, real points, payment processing, courier booking, email notifications or admin moderation. Connect a secure backend before collecting real customer information or processing exchanges.
